According to AI, most expression grammar production rules fall into 4 or 5 structural patterns:

	Pattern Type	Grammar Example				Generated AST Action
	1. Binary Infix	expression ::= expression "+" term	Create a BinaryExpr node with left & right children.
	2. Unary Prefix	factor ::= "+" primary			Create a UnaryExpr node with a single child and operator value.
	3. Pass-Through	expression ::= term			Forward the child node directly upward (po_node := l_child_node;).
	4. Terminal Leaf	primary ::= number_literal	Create a leaf node (NumberLiteral) using token metadata.
	5. Grouping / Wrapper	primary ::= "(" expression ")"	Pass through or wrap in a ParenthesizedExpr node.
